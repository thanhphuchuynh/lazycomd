---
title: lazycomd
description: One user-wide daemon for long-lived dev commands.
---

One user-wide daemon that runs, supervises and exposes your long dev
commands — proxies, tunnels, local service stacks — over an HTTP API.

Quitting the TUI stops nothing. The daemon owns process trees.

```bash
lazycomd serve          # daemon, foreground
lazycomd                # TUI (needs a TTY)
lazycomd ls             # CLI over the HTTP API
```

The default listener is a unix socket at
`~/.local/state/lazycomd/lazycomd.sock` (mode 0600). Optional TCP needs
`listen:` plus `token_file:`.

Source: [github.com/thanhphuchuynh/lazycomd](https://github.com/thanhphuchuynh/lazycomd).
